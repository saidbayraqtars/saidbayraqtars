### 👋 About

I build software that runs real businesses: order systems for distributors, ERP
integrations, field-sales apps and the desktop tools that sit next to an
accounting system all day. Most of my work talks to **VegaWin / VegaDB**
(SQL Server) and ships to customers as installable apps that update themselves.

- 🏢 **Bayraktar Yazılım** — own brands **Neva** (QR menu SaaS) and **ArcTeknik** (ERP & restaurant automation)
- 🔭 **Now:** a stand-alone B2B order platform — web, mobile and desktop, one deployment per customer
- 🧩 **Like:** ledgers that never lie, idempotent payments, tests that catch real bugs
- 📍 Samsun, Türkiye

### 🧠 How I work

- **The ledger is the truth.** Stock, cash and balances move only through one door, and every move can be reversed.
- **Ship for the real user.** Automation only matters if it survives production — rate limits, flaky networks, a bank that answers twice.
- **Test what can lose money.** Payments, pricing and permissions get tests before they get features.
